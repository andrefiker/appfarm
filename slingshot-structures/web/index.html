How it works & scoring

Pull the ball backward, up to 72 world units. Aim for the supports. Release to launch; Cancel or a second finger cancels. A small pull does not spend a shot. The dotted path uses the same fixed-step gravity as flight; it predicts free flight only, before any collisions.

Move every striped core 40 units sideways or 32 units down, or break it. Wood breaks, glass shatters, stone resists and metal is toughest. Each shot resolves for up to 7 seconds; residual motion is then frozen for the next turn. Retry restores the same layout.

Score = 1,000 for completion + 500 per unused shot + up to 500 × fraction of pieces broken. Each piece counts once. Precision records the fewest shots separately.

Endless uses six structural families with seeded materials and dimensions. Each candidate is checked for initial stability and a sampled winning shot. This checks the current engine, not every possible device or strategy.

Progress stays on this device. If interrupted during a shot, Continue restores the checkpoint before that shot, with that shot refunded. Saved checkpoints freeze settled pieces and clear old projectiles; they are turn checkpoints, not an exact mid-flight replay.

Sandbox: add a block, then tap an empty place above the ground to place it. Rotate changes its orientation. New blocks snap onto the highest overlapping surface. Undo removes your last block; Clear starts an empty workshop.
