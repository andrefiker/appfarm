Tower Stack 1.0.0 — offline physics stacking for Android 8+.

Five modes, three themes, real Matter.js rigid-body physics, local saves and
personal records, optional rotation, sound and haptics. No network, ads or accounts.

Package: com.andrefiker.towerstack / version 1.0.0 / code 1.
Signed with an Android debug certificate (not a Play Store production key).

The release workflow gates publication on rules/physics tests, browser mobile
playthrough, APK identity/permissions/signature/alignment/bundle verification,
and an offline Android emulator install/play/restore/collapse/restart check.
Physical phone testing has not been performed. Continue replays saved drops and
simulation ticks; very long sessions can take a moment. Abrupt process death may
return to the latest saved event. See README for exact scoring and failure rules.
