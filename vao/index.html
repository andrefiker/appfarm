Limpar tudo?

Remove todas as barras deste nível (dá para desfazer).

Como jogar

Construir: arraste a partir de uma âncora (quadrado vermelho) ou de um nó para criar uma barra. Cada material tem alcance e custo próprios.

Pista é onde o veículo roda. Madeira é barata e fraca. Aço é forte e caro. Cabo só aguenta tração.

Apagar: segure o dedo sobre uma barra ou nó, ou use o botão Apagar. Zoom: pinça com dois dedos; arraste o fundo para mover.

Testar: o veículo atravessa. As barras mudam de cor conforme o esforço — de azul (folga) a vermelho (ruptura). Se algo quebrar, veja o colapso em câmera lenta.

Pontuação: o que sobra do orçamento. Articulações giram livremente: só triângulos são rígidos.

Gire o aparelho para a horizontal.
