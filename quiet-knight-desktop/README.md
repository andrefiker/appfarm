# Quiet Knight for Windows

This desktop shell opens the existing Railway-hosted Quiet Knight at its original HTTPS origin, preserving same-origin account and multiplayer connections. It does not change or deploy the game or server. The page is remote and can change with the live deployment. Initial launch needs internet; offline computer play depends on the existing site's service worker completing its offline cache. Accounts and online rooms require internet. Desktop storage is separate from other browsers and apps; existing local saves do not automatically transfer. Notifications and other permission requests are disabled in this desktop shell.

Build with Node and npm: `npm ci` then `npm run build:windows`. Produces an unsigned per-user Windows x64 NSIS installer. Windows runtime testing and signing require a Windows environment and a trusted code-signing certificate respectively.

If NSIS compilation cannot run on the build host, `dist/win-unpacked` is the complete portable app. Zip its contents together; on Windows, extract the entire archive to a folder and run `Quiet Knight.exe` from that folder. Do not move the executable away from its companion files. This is a portable app, not an installer, and it has not been Windows-runtime qualified in the Linux build environment.

For a Linux host without Wine, first run `npm run build:windows` until the Windows `dist/win-unpacked` app has been produced, then use the native Linux compiler from the electron-builder NSIS 3.0.4.1 distribution: set `NSISDIR` to its directory and `QK_MAKENSIS` to its `linux/makensis`, then run `node installer/build.mjs`. This creates a per-user installer with desktop and Start menu shortcuts and a Windows uninstall entry. Uninstall removes the packaged files and shortcuts, retaining app data and unrelated files. The installer and app are unsigned. The installer uses a 32-bit NSIS stub and checks for 64-bit Windows; the packaged app is x64. Windows installation, launch, and uninstall still require qualification on Windows.

The native NSIS build stages a copy of the app with Chromium locale files limited to en-US, en-GB, pt-BR, and pt-PT to reduce installer size. All other application and runtime files, including license notices, are retained. This does not translate the live game's interface.
