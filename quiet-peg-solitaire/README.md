# Quiet Peg Solitaire — development build

Offline Android WebView puzzle. Package `com.andrefiker.quietpegsolitaire`, version `1.0.0`, minimum Android 8.0. No network permission or remote assets. All positions use exact integer geometry; a legal move removes the adjacent peg. English: 33 holes, empty center; European: 37 holes (the English cross plus four diagonal corner holes), empty center; triangular: 15 holes, top empty. European center vacancy is a traditional starting arrangement and is not advertised as guaranteed solvable.

Challenge and daily positions are generated by reversing legal moves from a single target. Their recorded solutions consist of the reverse sequence, with the actual jump count shown next to the board. A seeded PRNG makes generation reproducible. Hints search in a separate worker with a fixed node budget and report uncertainty if exhausted. Games, histories, settings and statistics are stored locally. The timer pauses when the app is backgrounded or the game screen is closed. Sound is synthesized locally; haptics use Android system feedback.

## Build and tests

`node tests/engine.test.js`; browser integration tests require Playwright and Chromium and a local HTTP server for `tests/browser.cjs`. `tests/drag.cjs` tests local-file input and hints. Android build: `gradle --offline assembleDebug` with Android SDK 35, Gradle 8.9, Java 17, and cached Android Gradle plugin 8.7.3. Debug signing is for development only.

## Release status

This is an incomplete development build. No device/emulator launch has been performed. The design still lacks requested polished move/removal and completion animations, grounded difficulty labels, comprehensive lifecycle/statistics tests, and full Android accessibility and gesture validation. The game has not met the requested release gate and has not been published. See the conversation for actual verification results.
