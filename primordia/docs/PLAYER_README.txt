PRIMORDIA 1.0.0
Become what survives.

Run Primordia.exe. Keep Primordia.pck beside it. Everything runs offline.

WASD / arrows: swim        Mouse: orient
Space: burst / bite        Shift: escape / specialized ability
E: evolve                 I: species
L: lineage                M: habitat map
Esc: pause                F11: fullscreen

Eat golden particles. Explore connected habitats. Gather 18 mutation and
60 energy to reproduce. Add, drag, rotate and resize structures in the
organism editor. Anatomy changes how you move, feed and survive.

Autosaves and settings:
%APPDATA%\Godot\app_userdata\Primordia\
The previous good save is retained as lineage.save.bak.
Uninstalling the game preserves your save data.

Windows 10/11 x64, OpenGL 3.3 graphics. No network or administrator access
is required. The build is unsigned, so Windows may show an unknown
publisher notice.
