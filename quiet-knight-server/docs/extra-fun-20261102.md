# Quiet Knight Emerald 1.3.0: twelve optional additions

Adds the user's twelve approved ideas to the existing Emerald game. Chess rules, the server protocol, board materials, square geometry and the existing signing identity are retained.

| Feature | Implemented behavior |
| --- | --- |
| Last survivor | A small red headband appears on each side's last remaining pawn. |
| Near-miss dodge | A king moving out of check ducks and straightens within one second. |
| Long-move trails | Long bishop and rook moves leave a brief line along their actual path. |
| Knight hoofprints | Horseshoe marks follow an L-shaped route, in either board orientation. |
| Pawn graduation | Cosmetic gold dots accumulate as a pawn advances; no powers or rule changes. |
| Royal indignation | A newly checked king wobbles and adjusts a small decorative crown. |
| Board weather | Rain, drifting dust, or fireflies appear only at the board edges. Off by default. |
| Sound themes | Wooden clicks, marble clacks, orchestral notes, cartoon tones, and the existing classic sounds. Synthesized locally. |
| Victory photograph | The existing postcard becomes directly available after a finished main-table game, including names, result, and final position. Android adds a bounded PNG document-save bridge. |
| Whole-game movie | A separate read-only dialog plays a game at 0.5×, 1× or 2×, with longer pauses on captures/checks, manual frames and a scrubber. Supports custom study starting positions. Incoming live moves close it. |
| Captured-piece audience | Already captured pieces briefly nod or bounce when another joins their tray. No reaction on returning from history or loading a game. |
| Secret interactions | The home knight cycles through neighing, bowing and refusing. No navigation or game action. |

Controls are under Settings → Play your way → Fun extras → More character. Weather has a selector; sound themes require master move sounds. Personality sounds retain their separate piece voices. Cosmetic board features respect Quiet Mode, move/playful switches, reduced motion, and backgrounding. Movies remain manually browsable when automatic playback is suppressed. Event animations last at most one second; optional ambient weather loops only while foregrounded.

## Boundaries and verification

Game movies work on the main table and local study sessions. Victory photographs apply to finished main-table games; the existing saved-game postcard remains available. Captured audiences apply to the main table's existing trays. No online messages, moves or score changes are sent by these features.

The new browser suite covers preference migration, all four new sound themes, mute/Quiet Mode, actual PNG creation and native payload, movie state isolation, incoming move closure, custom starts, weather, orientation, pawn badges, king reactions and captured audiences. Regression suites cover existing effects, draw consent, history, archive export and responsive geometry. Screenshots of the movie at 320 px, the final-position photograph and pawn decorations are inspected during release. Exact run results and final package hashes are recorded with the release artifact.

The Android package remains `com.andrefiker.quietknight.emerald`, versionCode 18. It is signed with the retained Emerald certificate SHA-256 `b313c3692a59487263ce4474c4adf2cd80bb4562fe582245c50d5e14fbffd08f`; the private key is excluded from the repository. Android 8+; target SDK 35; portrait; only INTERNET permission. Native save uses Android's document chooser, without broad file-storage permission.

No physical phone installation, audible speaker check, or Android document-picker interaction is claimed. The image bridge payload is exercised in browser tests; native code must also compile and pass Android lint. No production service, schema, or database change is required.
